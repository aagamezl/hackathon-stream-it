
## Core Fundamentals to Cover

## 1. How Computers Think
* What a program is (instructions executed by a computer).
* The idea of input → processing → output.
* Data types (numbers, text, boolean).
* Variables: naming, storing, and reusing values.

## 2. Logic and Flow
* Logic operators (AND, OR, NOT, EQUAL TO, GREATER THAN, LESS THAN).
* Boolean logic (true/false).
* Math operations (addition, subtraction, multiplication, division).
* Conditional statements (if/else) — decision making.
* Loops (for, while) — repeating actions.

3. Advanced Concepts & Presentations 
* Functions — grouping reusable logic.
* Events — responding to user actions (clicks, key presses)
