
# Hackathon Schedule: Learning to Code with Games

## 1. Introduction to Programming (45 min) - 16:15-17:00
- Welcome & setup (15 min)
  - Introduction to the workshop
  - Setting up the development environment
  - Quick tour of the code editor and browser tools
- How Computers Think (30 min)
  - What is a program? (10 min)
    - Instructions executed by a computer
    - Input → Processing → Output concept
  - Data Types & Variables (20 min)
    - Numbers, text, boolean
    - Naming, storing, and reusing values
    - Hands-on: Modifying game variables

## Short Break (5 min) - 17:00-17:05

## 2. Programming Session (55 min) - 17:05-18:00
- Logic and Operators (25 min)
  - Logic operators (AND, OR, NOT, comparisons)
  - Boolean logic in practice
  - Math operations in code
- Control Flow (30 min)
  - Conditional statements (if/else) - decision making
  - Loops (for, while) - repeating actions
  - Hands-on: Adding game mechanics

## Long Break (15 min) - 18:00-18:15
- Food and snacks
- Informal Q&A

## 3. Advanced Concepts & Presentations (35 min) - 18:15-18:50
- Functions & Events (20 min)
  - Grouping reusable logic
  - Responding to user input
  - Hands-on: Adding keyboard controls
  
- Showcase & Wrap-up (15 min)
  - Student presentations (5 min)
  - Recap of key concepts (5 min)
  - Resources for continued learning (3 min)
  - Final Q&A (2 min)
